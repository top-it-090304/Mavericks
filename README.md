## Об игре

**Dunk Elite** — минималистичная аркада, вдохновленная классическими баскетбольными флип-играми. Ваша цель — забрасывать мяч в кольцо, набирать комбо и ставить рекорды.

## Особенности

- 🏀 **Один бросок** — просто нажимай и отпускай
- 🎯 **Система комбо** — чем больше бросков подряд, тем выше множитель
- 🏆 **Рекорды** — соревнуйся с самим собой
- 💰 **Коллекция мячей** — открывай новые скины за звезды
- 📱 **Минималистичный дизайн** — ничего лишнего

## Как играть

1. Нажми на мяч и тяни вниз — чем сильнее тянешь, тем выше полетит мяч
2. Отпусти, чтобы сделать бросок
3. Попади в кольцо, чтобы заработать очко
4. Попадай подряд — получай множитель
5. Промахнешься — комбо собьется

## Технические детали

- **Движок:** Godot 4.4.1
- **Язык:** GDScript
- **Платформы:** AurorOS
